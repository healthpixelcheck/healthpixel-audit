# Security policy

## Reporting a vulnerability

Please report security problems privately. Do not open a public issue.

- E-mail: research@healthpixelcheck.org, or
- GitHub private vulnerability reporting: the **Security** tab of this repository → **Report a vulnerability**.

Include what you found, how to reproduce it and which version or commit you used. We aim to reply within a few working days and will agree a disclosure date with you once a fix is ready.

## Scope

This repository (the `healthpixel-audit` engine) and the web checker at https://check.healthpixelcheck.org that runs on it. Please do not test against websites you do not own, and do not run load tests against the web checker.
